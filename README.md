Repositório para códigos do curso de Análise e Desenvolvimento de Sistemas do Instituto Federal da Paraíba.

---

## 📂 Estrutura de pastas
 
O repositório está organizado por período letivo, com subpastas para
exercícios e projetos de cada disciplina.
 
```
IFPB/
├── 1PERIODO/
├── 2PERIODO/
│   ├── Exercicios/
│   │   ├── lista02/
│   │   ├── lista03/
│   │   ├── lista04/
│   │   ├── lista05/
│   │   ├── lista06/
│   │   ├── lista07/
│   │   ├── lista08/
│   │   └── lista09/
│   └── Projetos/
├── 3PERIODO/
├── 4PERIODO/
├── 5PERIODO/
├── 6PERIODO/
└── OUTROS/
    └── img/
```
 
- **`XPERIODO/`** — organiza o conteúdo por semestre cursado
- **`Exercicios/listaXX/`** — listas de exercícios propostas em disciplinas
- **`Projetos/`** — projetos maiores desenvolvidos durante o período
- **`OUTROS/`** — arquivos auxiliares (ex: imagens usadas neste README)
## 🎯 Sobre
 
Este repositório serve como registro do meu progresso ao longo do curso,
reunindo desde exercícios simples até projetos completos aplicando
conceitos de programação, estruturas de dados, banco de dados e
engenharia de software.
